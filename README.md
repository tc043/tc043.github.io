# Personal Portfolio - Tong Chun Mun

A clean, modern, and responsive personal portfolio website showcasing my skills, projects, and educational background as a Data Science graduate.

## 🚀 Live Demo
You can view the live site at [tc043.github.io](https://tc043.github.io/)

## ✨ Features
- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices using Bootstrap 5.
- **Hero Section**: Quick overview of my profile and contact details.
- **About Me**: Brief introduction and academic timeline.
- **Skills Matrix**: Categorized list of programming languages, web technologies, and AI/Data tools.
- **Project Showcase**: Cards highlighting key projects with descriptions and tech stacks.
- **Actionable Contact**: Clickable email and phone links for easy communication.

## 🛠️ Tech Stack
- **Structure**: HTML5
- **Styling**: CSS3, Bootstrap 5 (CDN)
- **Deployment**: GitHub Pages

## 📂 Project Structure
- `index.html`: Main entry point and single-page layout.
- `README.md`: This documentation file.
